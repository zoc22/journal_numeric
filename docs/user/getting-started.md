# Bienvenue sur le Journal Numérique

Ce guide vous aidera à faire vos premiers pas sur la plateforme, que vous soyez un administrateur de plateforme ou une nouvelle maison d'édition.

## Pour les Maisons d'Édition

### 1. Création de votre compte
Si vous souhaitez rejoindre la plateforme en tant que maison d'édition, vous devez d'abord vous inscrire sur le portail central.

### 2. Demande de création de maison
Une fois connecté, vous pouvez soumettre une demande de création pour votre maison d'édition. Vous devrez fournir :
- Le nom de votre maison.
- Une description courte.
- Un email de contact officiel.

### 3. Validation
Votre demande sera examinée par un administrateur de la plateforme. Une fois validée, vous recevrez une notification et vous deviendrez l'**Éditeur en Chef** de votre espace.

## Pour les Journalistes et Contributeurs

### 1. Rejoindre une maison
Les maisons d'édition publient régulièrement des **Appels à candidatures**. Vous pouvez les consulter sur le portail public.

### 2. Postuler
Soumettez votre CV et vos motivations directement via la plateforme.

### 3. Collaboration
Si votre candidature est acceptée, vous serez invité à rejoindre la maison d'édition et vous pourrez commencer à rédiger vos premiers articles.
